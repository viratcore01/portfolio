## ✨ What's inside

- **Live project sync** — `src/lib/github.ts` + `src/hooks/useGitHub.ts` fetch `api.github.com/users/viratcore01/repos` at runtime (1h localStorage cache, stale-while-revalidate). Search, language filter, sort, pinned-first ordering, stars/forks/live badges.
- **Full sections** — Hero (live repo/follower counts) · About · Skills · Projects · GitHub stats · AI · Experience · Contact · Footer. No dead `#` links, no `lorem ipsum`.
- **Working contact form** — validates, sends via FormSubmit AJAX with zero backend, falls back to prefilled `mailto:` if offline. Click-to-copy email.
- **Central config** — edit `src/config/site.ts` (pinned repos, excluded repos, curated descriptions/images) and the whole site follows.

## 🔁 How auto-update works

| Surface | Mechanism | Action needed |
|---|---|---|
| **Website Projects** | Runtime `fetch()` to GitHub API, no rebuild | Nothing — push a repo, it appears |
| **Website LeetCode** | Daily snapshot (`public/leetcode.snapshot.json`) + best-effort live refresh | Nothing — solve problems, numbers follow |
| **Portfolio README** (this file) | `node scripts/update-readme.mjs` via `.github/workflows/update-readme.yml` (daily 06:00 UTC + on push + manual) | Push this repo to GitHub once |
| **Profile README** (`viratcore01/viratcore01`) | Copy `PROFILE-README.md` + `PROFILE-WORKFLOW.yml` into that repo | One-time 2-minute setup (steps in `PROFILE-README.md`) |

```bash
npm install
npm run dev          # local dev
npm run build        # typecheck + production build
npm run readme:sync  # manually refresh README tables + snapshot now
```

To curate a repo (custom title/description/tags/image), add it to `CURATED` in `src/config/site.ts`. To pin/hide repos, edit `SITE.github.pinned` / `excluded`. To remove a placeholder description on GitHub itself, edit that repo's **About → description + homepage** — the site and README pick it up on next sync.

## 🚢 Deploy (Vercel, 2 min)

1. Push this folder to `github.com/viratcore01/portfolio`.
2. Vercel → New Project → import `portfolio` → defaults work (`npm run build`, `dist/`).
3. Done. Future pushes auto-deploy; new GitHub repos still appear with **no redeploy** (runtime fetch).
